# @docforge-cli/cli-darwin-arm64

Native binary for the [DocForge CLI](https://www.npmjs.com/package/@docforge-cli/cli) — macOS Apple Silicon (arm64).

**Do not install this package directly.** Install the main wrapper instead:

```bash
npm install -g @docforge-cli/cli
```

npm will automatically select and install this platform binary via `optionalDependencies`.

## Platform

- OS: macOS (darwin)
- Arch: arm64 (Apple Silicon M1/M2/M3)
