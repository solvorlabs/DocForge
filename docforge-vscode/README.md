
# DocForge for VS Code

> Turn any library's documentation into a prompt-ready `.context.md` file, pinned to the exact version you're using.

## Why DocForge?

AI coding tools (Cursor, Copilot, Claude) hallucinate outdated APIs because their training data is months or years old. Modern libraries change fast — import paths, prop names, required directives, peer dependencies.

DocForge solves this by:
1. Crawling the actual documentation for **your exact library version**
2. Using Gemini AI to extract **gotchas** — the patterns that most commonly break AI codegen
3. Writing a structured `.context.md` file you can drop into any AI tool's context

## Commands

| Command | Description |
|---------|-------------|
| `DocForge: Generate Context File` | Main command — choose input type and generate |
| `DocForge: Generate Context for Selected Package` | Right-click a package name in the editor |
| `DocForge: Update Existing Context` | Re-fetch context for the current `.context.md` |
| `DocForge: Detect from package.json` | Auto-detect packages from your project |

## Quick Start

1. Install the extension
2. Open a project folder
3. Press `Ctrl+Shift+P` (or `Cmd+Shift+P` on Mac)
4. Type `DocForge: Generate Context File`
5. Choose `npm Package` and enter e.g. `react-bits@2.1.4`
6. Wait 30–90 seconds for crawling + AI structuring
7. A `.context.md` file is created in your workspace root

## Configuration

| Setting | Default | Description |
|---------|---------|-------------|
| `docforge.backendUrl` | `https://api.docforge.dev` | Backend URL. Use `http://localhost:8000` for local dev. |
| `docforge.outputPath` | `.context.md` | Output file path relative to workspace root |
| `docforge.autoOpenFile` | `true` | Auto-open the generated file |
| `docforge.apiKey` | `""` | API key for enterprise features |

## Local Development

To run against a local backend:

1. Start the DocForge backend: `make dev-backend` (from the repo root)
2. Update setting: `"docforge.backendUrl": "http://localhost:8000"`

## What's in a `.context.md` File?

```markdown
# react-bits@2.1.4 — DocForge Context File
> Generated by DocForge | Last verified: 2026-03-13

## AnimatedList

**Install:**
\`\`\`bash
npx jsrepo add https://reactbits.dev/components/animated-list
\`\`\`

**Import:**
\`\`\`typescript
import AnimatedList from '@/components/AnimatedList'
\`\`\`

**⚠️ Gotchas (Common AI Codegen Errors):**
- Must add `'use client'` directive in Next.js App Router
- Requires `framer-motion` as peer dependency — install separately
```

## Using with AI Tools

**Cursor:** Type `@context.md` in any chat to inject the context.

**Claude:** Drag the `.context.md` file into the chat window.

**GitHub Copilot:** Open the file and use "Copilot: Use this file as context".
