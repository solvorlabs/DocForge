## Dialog

**Install:**
```bash
npm install @radix-ui/react-dialog
```

**Import:**
```typescript
import * as Dialog from '@radix-ui/react-dialog'
```

**Props:**
| Prop | Type | Required | Default |
|------|------|----------|---------|
| open | boolean | — | null |
| onOpenChange | (open: boolean) => void | — | null |
| modal | boolean | — | true |

**⚠️ Gotchas (Common AI Codegen Errors):**
- Make sure to import the Dialog component and its sub-components correctly.
- The Dialog component requires a trigger element to be passed as a child of the Dialog.Root component.

**Usage:**
```tsx
import * as Dialog from '@radix-ui/react-dialog';

function MyDialog() {
  const [open, setOpen] = React.useState(false);

  return (
    <Dialog.Root open={open} onOpenChange={setOpen}>
      <Dialog.Trigger asChild>
        <button>Open Dialog</button>
      </Dialog.Trigger>
      <Dialog.Portal>
        <Dialog.Overlay />
        <Dialog.Content>
          <Dialog.Close>
            Close
          </Dialog.Close>
          <p>This is a dialog</p>
        </Dialog.Content>
      </Dialog.Portal>
    </Dialog.Root>
  );
}
```
