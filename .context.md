## react-bits

**Install:**
```bash
yarn add react-bits
```

**Import:**
```typescript
import { View, Text, Image, StyleSheet } from 'react-bits';
```

**Peer Dependencies:**
- `react`

**Props:**
| Prop | Type | Required | Default |
|------|------|----------|---------|
| style | object | — | null |
| children | ReactNode | — | null |

**⚠️ Gotchas (Common AI Codegen Errors):**
- Requires React version >=16.0.0
- Must import StyleSheet and use it to declare styles

**Usage:**
```tsx
import React from 'react'; import { View, Text, Image, StyleSheet } from 'react-bits'; class Foo extends React.Component { render() { return ( <View style={styles.foo}> {this.props.children} </View> ); } } const styles = StyleSheet.create({ foo: { width: 100, height: 100, backgroundColor: '#ff00ff', }, });
```
