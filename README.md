# DocForge

> Turn any library's documentation into a prompt-ready `.context.md` file, pinned to the exact version you're using.

## The Problem

AI coding tools hallucinate outdated APIs because their training data is months or years old:

- `react-bits` v2 installs with `npx jsrepo add ...` — not `npm install`
- `@tanstack/react-query` v5 broke its entire API from v4
- Next.js App Router requires `'use client'` that AI tools routinely forget
- Studies show AI generates non-existent APIs in **5.2% of commercial code** and **21.7% of open-source projects**

DocForge fetches the actual docs for **your exact version** and extracts the specific patterns that break AI codegen.

---

## How It Works

```
[VS Code Extension / CLI / MCP Server / Web UI]
                ↓  HTTP POST /api/context
         [DocForge FastAPI Backend]
                ↓
     [Crawl docs with Playwright + httpx]
                ↓
  [Structure with Gemini 2.0 Flash → Groq fallback]
                ↓
     [Cache in Supabase / in-memory]
                ↓
     [Write .context.md / .json to disk]
```

All clients (extension, CLI, MCP, web) are thin HTTP wrappers. All the heavy lifting — crawling, AI structuring, caching — runs in the Python backend.

---

## Components

| Component | Stack | What it does |
|-----------|-------|--------------|
| `backend/` | FastAPI + Python | Crawl → structure → cache pipeline, JWT auth, OAuth |
| `docforge-vscode/` | TypeScript + VS Code API | Sidebar panel with auth, context generation from the editor |
| `docforge-cli/` | Rust binary + npm wrapper | Terminal CLI, installable via npm |
| `docforge-mcp/` | Python + MCP SDK | Lets AI assistants fetch docs autonomously |
| `docforge-web/` | Next.js 14 + Three.js + Radix UI | Web UI with live job progress and auth |

## Quick Start

### CLI (recommended for first-timers)

```bash
npm install -g docforge-cli

dcf login                              # sign in via browser
dcf generate react-bits@2.1.4
dcf generate fastapi==0.110.0
dcf generate https://github.com/DavidHDev/react-bits
dcf detect                             # reads package.json, generates all deps
```

### VS Code Extension

1. Install: search `DocForge` in the VS Code Marketplace
2. Click the DocForge shield icon in the Activity Bar to open the sidebar
3. Sign in with Google, GitHub, or email/password
4. `Ctrl+Shift+P` → type **DF:** to see all commands
5. Pick **DF: Generate Context File** → choose source type → choose format
6. `.context.md` appears in your workspace root after 30–90s

When using **DF: Detect from package.json**, select multiple packages — they all run in sequence and get appended into one `.context.md` file.

### Web UI

```bash
make dev-backend    # backend at http://localhost:8000
make dev-web        # frontend at http://localhost:3000
```

### MCP Server (Claude Desktop / Cursor / Windsurf)

Ask your AI naturally:

> "Add AnimatedList from react-bits@2.1.4 to my Next.js app"

The AI calls `get_context("react-bits@2.1.4")` on its own and gets accurate v2.1.4 API docs. See [docforge-mcp/README.md](docforge-mcp/README.md) for config.

### Direct API

```bash
make dev-backend          # starts backend at http://localhost:8000

# Submit a job
curl -X POST http://localhost:8000/api/context \
  -H "Content-Type: application/json" \
  -d '{"input":"react-bits@2.1.4","input_type":"npm","output_format":"context_md"}'
# → {"job_id":"abc-123","status":"queued"}

# Poll for result
curl http://localhost:8000/api/context/abc-123
# → {"status":"complete","output":"# react-bits@2.1.4 ..."}
```

## Example Output

```markdown
# react-bits@2.1.4 — DocForge Context File
> Generated by DocForge | Last verified: 2026-03-14

## AnimatedList

**Install:**
npx jsrepo add https://reactbits.dev/components/animated-list

**Import:**
import AnimatedList from '@/components/AnimatedList'

**Props:**
| Prop  | Type     | Required | Default |
|-------|----------|----------|---------|
| items | string[] | yes      | —       |
| delay | number   | —        | 0.1     |

**Gotchas (Common AI Codegen Errors):**
- Add 'use client' at the top of any Next.js App Router file using this component
- framer-motion must be installed separately — it is not bundled
- The import path is @/components/AnimatedList, not react-bits/AnimatedList
```

## Supported Input Methods

| Type | Example |
|------|---------|
| npm package | `react-bits@2.1.4` or `@tanstack/react-query@5.0.0` |
| PyPI package | `fastapi==0.110.0` or `fastapi` (resolves latest) |
| Documentation URL | `https://reactbits.dev` |
| GitHub repo | `https://github.com/DavidHDev/react-bits` |
| Paste (HTML / Markdown) | paste directly in the extension or web UI |

URLs containing `github.com` are automatically routed to the GitHub ingester (README + /docs + `.d.ts` files).

## Output Formats

| Format | Extension | Best for |
|--------|-----------|----------|
| `context_md` | `.context.md` | AI prompts — structured, gotcha-focused |
| `json` | `.json` | Large projects, programmatic use, custom tooling |

When using **multiple packages**, all results are appended into a single file with `---` separators — one context file for your whole project.

## Authentication

DocForge uses JWT-based auth across all clients. You can sign in with:

- **Google OAuth** — one-click sign-in from the VS Code sidebar or web UI
- **GitHub OAuth** — one-click sign-in from the VS Code sidebar or web UI
- **Email + password** — standard account registration

The VS Code extension stores the JWT in `~/.config/docforge/config.toml` (shared with the CLI). The CLI uses the same file via `dcf login`.

## AI Fallback Chain

| Engine | Role | Limit |
|--------|------|-------|
| Gemini 2.0 Flash | Primary structuring | 1,500 req/day (free) |
| Groq LLaMA 3.3 70B | Automatic fallback on 429 | 14,400 req/day (free) |

If Gemini hits its daily quota, the pipeline silently falls back to Groq — no action needed.

## Compared to Alternatives

| Tool | Gap |
|------|-----|
| Context7 | Serves latest docs, no version pinning, requires live API call |
| context-hub (Andrew Ng) | Hand-curated, limited library coverage |
| Cursor @Docs | No gotcha extraction, always fetches latest |
| contextmd | Raw dump, no AI structuring |

DocForge is the only tool that is simultaneously **version-pinned**, works on **any library**, **runs offline** (the file is local after generation), and extracts **gotchas**.
